Acesso ao GitHub

Os botões Aceitar/Recusar disparam o workflow set-status.yml no repositório. Crie um fine-grained personal access token com acesso apenas a este repositório e permissão Actions: Read and write. O token fica salvo só neste navegador.

Instalar no iPhone

  1. No Safari, toque em Compartilhar (quadrado com seta para cima).
  2. Escolha Adicionar à Tela de Início.
  3. Abra o app pelo ícone da Storopack. As notificações só funcionam no iPhone a partir do app instalado.
